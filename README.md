# ⚡ Kavin V — Interactive 3D Portfolio

A single-page portfolio website with an animated 3D background and an electric lightning cursor.

**🔗 Live demo:** https://Kavin1717.github.io/kavin-portfolio/

---

## 👋 About

I’m **Kavin V**, an Electrical & Electronics Engineering graduate (B.E., CGPA 8.97/10) from Tiruppur, India. I work with Modbus device integration, Building Management Systems (BMS), embedded devices and MEP QA/QC, and I’m growing into networking and network security.

## ✨ Features

- 🌌 Animated 3D wireframe background built with Three.js, reacting to mouse movement and scroll
- ⚡ Electric lightning cursor, with a burst of bolts on click or tap
- 📜 Experience timeline, projects, education, certifications and skills
- 🔢 Animated counters and scroll-reveal effects
- 🌗 Automatic light and dark mode
- 📱 Fully responsive, from phones to desktops

## 🛠️ Built With

- HTML5, CSS3 and vanilla JavaScript
- [Three.js](https://threejs.org/) (r128) for 3D graphics
- Canvas 2D API for the lightning effect
- Google Fonts (Space Grotesk)

## 🚀 Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Kavin1717/kavin-portfolio.git
   ```
2. Open `index.html` in your browser. No build step is needed.

## 🌍 Deploy on GitHub Pages

1. Go to **Settings → Pages**.
2. Under **Source**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/ (root)**, then click **Save**.
4. Your site will be live in 1–2 minutes at `https://Kavin1717.github.io/kavin-portfolio/`.
